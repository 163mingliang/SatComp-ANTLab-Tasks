# 任务B｜算网协同任务处理建模与仿真

## 1. 基础任务（必做）

使用Python构建包含3—5个计算节点和若干计算任务的算网模型。各节点具有不同的计算能力，节点之间具有不同的传输带宽，**每个计算任务具有指定的来源节点、数据大小和计算量。**

假设计算任务可以在本地执行，也可以通过网络传输至其他节点执行，完成以下两种任务分配策略：

- **计算优先策略：**根据任务计算量和节点计算能力，选择预计计算时间最短的执行节点。
- **算网协同策略：**综合考虑任务数据传输时间和计算时间，选择预计任务完成时间最短的执行节点。

其中，任务传输时间可根据数据量和链路带宽计算，计算时间可根据任务计算量和节点计算能力估算。

要求程序完成以下功能：

（1）支持设置计算节点、任务需求和节点间传输带宽等参数。

（2）输出各任务的执行节点、数据传输时间、计算时间及预计完成时间。

（3）设计至少两组实验场景，例如任务数据量较小和较大两种情况，对比计算优先与算网协同策略的性能差异。

基础任务中可假设任务独立执行、网络链路状态固定，不要求建立真实卫星轨道模型。

## 2. 进阶任务（选做）

进一步考虑计算排队、链路传输时延、多跳网络传输或计算节点负载变化等因素，分析不同网络和计算条件对任务调度结果的影响。

同时，也可进一步补充动画演示。

## 3. 提交要求

提交Python源代码、测试数据、实验结果及简要说明，介绍算网模型、任务分配方法及实验发现。

## 测试数据参考

参见 [`datasets/task_b/`](../datasets/task_b/)。样例采用**单跳直连**模型，不考虑网络拥塞、排队或多跳路由；任务在来源节点执行时传输时间为0。建议使用统一单位：数据大小MB，带宽Mbps，计算量GOp，节点计算能力GOp/s；计算公式和单位换算见[数据说明](../datasets/README.md)。
